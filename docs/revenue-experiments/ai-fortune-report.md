# 수익 실험 #1 — AI 운세 리포트

> Office → Ventures #13 "AI 운세 리포트 (수익 실험 #1)" 의 계획 전문.
> 상태: **아이디어 / 매출 0원**. 실제 입금 전까지 어떤 매출 숫자에도 들어가지 않는다.
> 작성: 2026-11-17. 법·세무 내용은 조사 요약이며 법률 자문이 아니다. "확인 필요" 표시 항목은 판매 전에 확인한다.

## 1. 결론 먼저

- **시장은 있다.** 점신 누적 다운로드 1,700만, 포스텔러 가입자 750만, 주 이용층 2030(점신 MAU의 65.6%). 가격대는 990원 소액 리포트부터 월 3,900원 구독, 사람 상담 5,000–20,000원/10분까지 넓다. ([한국경제 2026-02](https://www.hankyung.com/article/2026021070861), [아주경제 2026-02](https://www.ajunews.com/view/20260213163857733), [sajuai.io 가격 비교](https://sajuai.io/ko/explore))
- **앱으로 경쟁하면 진다.** 무료 일일 운세·990원 리포트는 대형 앱이 이미 차지했다. 1인이 이길 수 있는 곳은 "특정 사람을 위한, 사람이 검수한 1:1 리포트"다.
- **그래서 앱을 만들지 않는다.** 크몽에 상품 1개, 인스타그램 계정 1개, 리포트 템플릿 1개로 14일 안에 첫 결제를 받아 본다. 추가 비용 0원(이미 쓰는 AI 구독 사용).
- **주의:** 크몽에는 "AI 사주로 월 300" 같은 53만 원짜리 부업 강의가 많고, 언론은 이를 실제 수입이 기대에 못 미치는 "클릭부업"으로 보도했다. 강의를 사지 않는다. ([문화일보](https://www.munhwa.com/article/11569391), [크몽 예시](https://kmong.com/gig/769184))

## 2. 상품 (MVP)

| 항목 | 내용 |
|---|---|
| 이름(예) | "개발자·취준생을 위한 커리어 운세 리포트" — 대표가 실제로 아는 고객층 |
| 형태 | PDF 3–5쪽: 성향 요약 / 올해·다음 분기 일 흐름 / 잘 맞는 일하는 방식 / 주의할 시기 / 한 줄 행동 제안 |
| 제작 | 생년월일(+선택: 태어난 시간) → AI 초안 → **직접 읽고 고쳐서** 전달. 사람이 검수했다는 점이 990원 앱과의 차이 |
| 전달 | 크몽 메시지로 PDF 전달, 주문 후 24시간 이내 |
| 가격 테스트 | 9,900원(1주제) / 19,900원(커리어+관계 2주제). 크몽 사람 상담형 리포트는 59,000원부터라 9,900원은 진입가 ([크몽 예시](https://kmong.com/gig/571618)) |
| 하지 않는 것 | 투자·건강·법률 판단, 불안을 자극하는 표현("액운", "큰일 난다"), 결과 보장 |

## 3. 판매 경로: 크몽 + 인스타그램

**왜 크몽인가 (직접 계좌이체 대신)**
- 결제·에스크로·분쟁 처리를 플랫폼이 한다 → 카드 결제 연동, 환불 응대 부담이 작다.
- 얼굴·실명·계좌번호를 고객에게 노출하지 않는다 (요구사항: 낮은 노출).
- 정산 시 원천징수(통상 사업소득 3.3%) 후 지급되는 구조라 소득 기록이 남는다. **확인 필요:** 판매자 등록 시 크몽 정산 안내에서 개인 판매자 원천징수 방식·수수료율을 직접 확인.

**인스타그램은 유입만**
- 계정: 개인 계정과 분리된 브랜드 계정. 얼굴 없이 리포트 샘플 이미지·짧은 카드뉴스.
- 첫 2주 게시물 6개: 샘플 리포트(가상 인물) 3, "개발자 유형별 일하는 방식" 같은 무료 콘텐츠 3.
- 프로필 링크 = 크몽 상품 페이지. DM으로 생년월일을 받지 않는다(개인정보는 크몽 주문서에서만).
- 유료 광고·팔로워 구매 없음 (대표 승인 전 지출 금지).

## 4. 첫 고객까지 순서 (14일)

1. **D1** 리포트 템플릿 1개 완성, 가상 인물 샘플 2개 제작 (이 저장소의 `docs/` 에 보관).
2. **D2** 아래 5장의 "법·세무 확인" 중 (1) 국비 훈련 영향부터 확인. 문제가 있으면 여기서 멈추고 판단.
3. **D3** 크몽 판매자 가입, 상품 등록(고지문 포함, 5장 참고). 심사 대기.
4. **D3–D14** 인스타 게시물 6개, 지인 3명에게 정가 구매 요청(무료 제공 아님 — 결제 경험 자체를 검증).
5. **첫 입금 시** Office → Finance에 `사업 매출` 로 기록, 관련 사업 = #13. Ventures 단계를 `매출 발생` 으로.
6. **D14 판정** 0건이면 가격·주제·채널 중 **하나만** 바꿔 14일 1회 더. 그래도 0건이면 종료하고 기록.

측정: 게시물 도달, 프로필 방문, 크몽 상품 조회, 문의, 결제. 매출과 제작 시간(Office → Productivity 업무 기록)을 함께 본다. 1건당 제작 30분 이내가 목표.

### 확인 필요 (판매 전에)
1. **국비 훈련(내일배움카드) 훈련장려금, 실업급여 수급 중이라면 그 영향.** 사업자등록이나 부업 소득이 수급 자격에 영향을 줄 수 있다. 훈련기관 담당자 또는 HRD-Net·고용센터에 먼저 문의. (조사로 확정하지 못함)
2. 크몽 개인 판매자 정산 시 원천징수 방식과 수수료.
3. 테스트 이후 계속 판매하면 간이과세자로 등록할지 — 세무서·홈택스 상담(무료).

### 권장 (의무 아님)
- 상품 설명 첫 줄: "AI 보조로 작성하고 직접 검수한 **오락·자기이해용 콘텐츠**입니다. 미래를 보장하지 않으며 투자·건강·법률 판단의 근거로 쓰지 마세요."
- 환불 정책: "작업 시작 전 전액 환불, PDF 전달 후에는 환불 불가 — 주문 전 샘플 리포트를 확인하세요"를 상품 페이지에 명시 + 샘플 이미지 제공(시험 사용 조치).
- 개인정보: 생년월일만 받고(시간은 선택), 전달 후 30일 내 삭제. 이름 대신 닉네임.
